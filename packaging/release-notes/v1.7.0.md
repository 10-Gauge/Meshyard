If you're on 1.6.0, the app offers this update when you open it. Otherwise download **Meshyard.exe** below.

## A new name

The app is now called **Meshyard**, with a new icon. Everything works the same as before, and your settings, tools, search index and exports come along on their own the first time you open it. Nothing needs to be downloaded or indexed again.

## New

- **Game menu.** The top of the window has a game menu (CryEngine Games) next to the build picker.
- **Find data files.** A new button looks through the usual game folders on every drive and lists every CryEngine data file it finds, with its build and size. Pick one to browse, or click **Browse…** to choose a file yourself. The app still runs the same search on its own the first time it starts, so most people never need it.
- **Choose data file.** If no game data turns up, you can now point the app straight at the data file instead of hunting for the right folder.

## Good to know

- Your data folder moved from `%LOCALAPPDATA%\sc-sandbox` to `%LOCALAPPDATA%\Meshyard`. If you open an older version after updating, it starts from scratch.
- The Blender sidebar tab is now called **Meshyard**. Click **Install add-ons** on the Blender sandbox page once to update it.
- For anyone using the command line, it's now `meshyard` instead of `sc-sandbox`.
- This release also comes as `SC-Asset-Browser.exe`, the same file under the old name, so older versions can still find the update.

The [README](https://github.com/10-Gauge/Meshyard#readme) has the full walkthrough.
