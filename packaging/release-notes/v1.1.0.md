Download **SC-Asset-Browser.exe** below and double-click it, same as before.

## What's new

- **Updates itself.** Every time you open the app it checks for a newer version. If there is one, a bar at the top lets you update with one click: it downloads the new exe, checks it, swaps it in and restarts. This is the last version you'll need to download by hand.
- **American spelling** throughout the app, so it's "armor" everywhere now.
- **MIT license.** The code is now open source. Game files and anything you extract from them still belong to the company that made the game.

## Good to know

- Blender is still a separate, free install, only needed for the gear and weapon switches, FBX, USDZ and `.blend` export, and the sandbox.
- Windows SmartScreen may warn you the first time because the exe isn't code-signed. Click *More info*, then *Run anyway*.

The [README](https://github.com/10-Gauge/SC-Asset-Browser#readme) has the full walkthrough.
